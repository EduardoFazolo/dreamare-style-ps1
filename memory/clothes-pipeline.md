The user's pipeline for character clothes (2026-10-26):
1. **Research** = games from the PS1/PS2 era whose setting matches the scene's archetype. A creepy village means RE4 Ganados, Siren, Fatal Frame 2, Silent Hill. Horror means horror games of that era. Modern and rich (the lizard stock brokers) means modern PS2 rich or suited characters. The clothes must look like they come from those games.
2. **Design** the outfit for one body archetype.
3. **Model** the body to fit the outfit.
4. **Textures** are real-life, the way the faces use real photos.

**Why:** the first concepts cut from Met museum costumes had no period. The next ones, plain 90s clothes made from CC0 fabric scans, were "closer" but "don't look like any ps1/ps2 game at all". Research means game references for the archetype, not fabric or costume archives.

**How to apply:** start every outfit from a reference sheet of era games matching the scene. Write down how those games built the clothes (silhouette, palette, texture look) before drawing. Related: [[clothes-degrade-rejected]], [[artist-method]], [[character-engine-v2]].

**2026-10-26, RE villagers:** the user wants a NEW way to build the bodies and clothes, so characters look like the game references. The rules:
- **Real 3D.** No 2D pictures or projected AI images; they stopped my Klein "design picture" step: "THEY NEED TO BE IN 3D".
- **Not re-skinned stock garments.** Recolouring the MakeHuman garments was the old method; it doesn't count.
